# Déclarer depuis Discord (ADR 0010)

Un membre qui n'a pas l'extension sous la main (téléphone, autre ordinateur) déclare un flood, un convoi ou une chasse sur une page de l'Espace d'alliance, ouverte par un lien épinglé sur le Discord de l'alliance. La page chiffre la déclaration dans le navigateur avec la Clé d'alliance : le site ne garde que du chiffré, et rien en clair ne passe par Discord. Décision de fond : `../adr/0010-declarer-depuis-discord.md` ; Envois : `site-envois.md` ; Discord : `site-discord.md`.

## Décisions de cadrage (2026-11-04, avec le joueur)

- **Le lien** : le panneau « Discord » de l'espace (Admins) donne « Copier le lien » et, quand le webhook des annonces est enregistré, « Poster sur Discord » : le **navigateur de l'Admin** ouvre ce webhook avec la Clé d'alliance et y poste « Déclarez un flood, un convoi ou une chasse sur Optizzz : <lien> » (lien entre chevrons, sans aperçu, `allowed_mentions` vide). Le site ne poste rien et ne lit toujours pas ce webhook. L'Admin épingle le message dans Discord.
- **Site seulement** : les déclarations s'affichent sur le site (Floods, Convois et Solde, Chasses, Mouvements, État), pas dans le jeu. L'extension ne change pas (ni code qui tourne, ni permission, ni `data_collection_permissions`, ni fiche des stores) : l'encart « Floods en route vers l'alliance » de la page Armée ne montre pas un flood déclaré. À revoir après usage.
- **L'heure** : un champ « Arrivée » (ou « Retour ») avec « À | Dans ». « À » (par défaut) lit une heure de Paris comme le jeu l'affiche (« 18h12 », « 18:12 », « 18h »), aujourd'hui si elle est à venir, sinon demain ; « Dans » le temps qui reste (« 2h30m », « 45m »). L'heure retenue s'écrit dessous (« arrivée demain 8 h 05 »).
- **Un convoi déclaré compte partout**, Solde compris : sans Demande il est un Envoi `declared-transits` ; pour une Demande validée du destinataire (facultatif), un Envoi `declared-convoys`, au format de « Déclarer un convoi » (`site-demandes.md`), que l'extension lit déjà pour l'encart des Demandes. Les convois déclarés depuis l'onglet Demandes entrent donc eux aussi dans le Solde.
- **L'extension l'emporte** : chaque page, après déchiffrement, cache une déclaration qu'un Envoi de l'extension du même membre recouvre, à 2 minutes près : un flood quand l'extension voit au moins autant d'attaques sur la même cible ; un convoi quand elle voit le même (expéditeur, destinataire, quantités), en route ou livré ; une chasse quand le journal des chasses ou l'état « Chasses » du membre la montre (mêmes cm²). Le site n'en sait rien.
- **Pas d'annonce Discord** pour une déclaration (le membre est déjà sur Discord), ni de rappel du site.

## Choix faits en codant

- **Trois catégories d'Envoi**, sans case à cocher (la déclaration est elle-même l'accord), gardées au plus 100 jours par le site et effacées 90 jours après l'arrivée ou le retour : `declared-floods` (cible, nombre d'attaques de 1 à 200, arrivée), `declared-transits` (destinataire, nourriture, matériaux, arrivée), `declared-hunts` (cm², retour). L'expéditeur est le Joueur de l'Envoi, pas un champ du chiffré. Chaque déclaration est sa propre ligne, d'empreinte tirée au hasard ; « Retirer » efface la ligne (le site vérifie que c'est le Joueur du compte).
- **Un seul point d'entrée** : `envois.declare` (tRPC) pour les quatre catégories déclarées, `declareConvoy` disparaît. Le service des Envois (`saveEnvoi`) applique les mêmes règles qu'aux autres listes (version la plus haute de la clé, chiffré seulement).
- **La fusion** se fait dans `useSpaceEnvois` (`mergeDeclarations`) : toutes les vues de l'Espace reçoivent les listes complètes, marquées `declared`. Un flood déclaré devient une ligne par attaque, sans prise attendue (« — », elle vient du Plan de flood) ni armée ; un convoi est « en route » avant son arrivée, « livré » après (il compte alors dans le Solde) ; une chasse n'a pas de nombre de fourmis.
- **La marque « déclaré »** : une pastille en pointillés, avec le mot (jamais la couleur seule, ADR 0003), dans Floods, Convois, Chasses et Mouvements (« 3 déclarés » dans un groupe). La note de l'onglet Floods l'explique.
- **La page** : `/spaces/<id>/declarer`, « Se connecter » d'abord (retour ici), puis la Phrase de chiffrement sur un nouvel appareil (avec « Se souvenir sur cet appareil ») ; un non-membre est renvoyé vers la page de l'espace. Les cibles proposées viennent de la carte publique du serveur entière (`/api/<serveur>/map`), comme les alliances des Convois : demander quelques pseudos dirait au site qui l'alliance vise. Sous le formulaire, « Vos déclarations » à venir, chacune avec « Retirer ».
- **Limite** : un membre qui n'envoie pas « Floods » reste « n'envoie pas Floods » dans les statistiques, même avec des floods déclarés.
